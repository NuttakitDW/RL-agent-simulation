Watch a PPO agent learn to trade — live, in your browser.

This is not a recording. The agent below is a tiny neural network with random weights. Press ▶ Play and PPO starts training it: collect a 200-step rollout on a synthetic market → compute advantages → run K=5 epochs of clipped-surrogate gradient updates → repeat. Each pass through that loop is one episode. The reward curve below tracks real per-episode reward; you'll see it climb as the network actually learns. The whole loop runs in JavaScript with hand-written backprop.
